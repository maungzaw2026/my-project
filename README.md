## ဖိုင်တွေအကြောင်း

- `extracted_code.py` - အဓိကကုဒ်ထုတ်ယူတဲ့ဖိုင်
- `open.py` - ဖိုင်ဖွင့်ခြင်းဆိုင်ရာ လုပ်ဆောင်ချက်များ
- `requirements-1.txt` - လိုအပ်တဲ့ Python package များစာရင်း
